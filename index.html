    PRIVACY & INSTALL

    화면에 보이는 데이터는 이 브라우저와 내 컴퓨터의 수집기(127.0.0.1:47777) 사이에서만 오갑니다. 사이트 서버로는 에이전트 데이터를 보내지 않으며, 사이트는 페이지 조회 수만 쿠키 없이 집계합니다.

    설치하면 이 컴퓨터에서 바뀌는 것:

    • ~/.agent-orbit — 수집기와 최근 7일 기록 (프롬프트·명령의 앞부분, 파일 이름, 토큰 수). 7일이 지나면 자동으로 지워집니다.
    • 로그인 시 자동 실행 — macOS ~/Library/LaunchAgents/dev.agentorbit.collector.plist, Linux ~/.config/systemd/user/agent-orbit.service
    • Claude Code 연결 시 — ~/.claude/settings.json의 hooks 항목 4개: 세션 시작, 도구 실행 전·후·실패 (최초 원본은 settings.json.orbit-bak)
    • Codex 연결 시 — ~/.codex/hooks.json의 hooks 항목 3개: 세션 시작, 도구 실행 전·후. 그리고 ~/.codex/config.toml의 승인 기록
    • macOS에서 세션이 시작되면 미니 창이 떠요. 아래 "세션 시작 시 미니 창" 스위치로 끌 수 있어요.
    • Codex 사용 한도는 Codex 공식 app-server(codex app-server)로 5분마다 읽습니다. Codex 가 자기 로그인으로 OpenAI 에 묻는 것이라 Tycho 는 로그인 정보를 보지 않습니다.
    • "Claude 사용 한도 보기"를 켜면(기본은 꺼짐) 수집기가 Claude Code 로그인 정보(macOS 키체인 또는 ~/.claude/.credentials.json)를 읽어 Anthropic(api.anthropic.com)에서 5시간 · 주간 한도를 5분마다 가져옵니다. 로그인 정보는 Anthropic 으로만 보내고 저장하지 않으며, 비용이나 한도 차감은 없습니다.

    모두 지우기: 터미널에서 tycho uninstall — 훅, 자동 실행, 설치 파일, 기록을 한 번에 지웁니다. 연결 해제만 하려면 위 에이전트 카드의 해제 버튼을 쓰세요.
